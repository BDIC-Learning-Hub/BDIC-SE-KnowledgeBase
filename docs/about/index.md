# 关于本项目

欢迎访问 BDIC 软件工程知识库！

## 项目简介

本知识库是为北京都柏林国际学院（BDIC）软件工程专业学生创建的学习资源平台，包含：

- 📚 **课程指南**：所有专业课程的详细介绍和学习建议
- 📝 **学习资料**：往年试卷、课件、参考资料
- 💡 **经验分享**：学长学姐的学习心得和建议
- 🔗 **资源链接**：实用的学习工具和外部资源
