## 课程简介

个人理解是形式化建模，用手写的形式写一些算法的思路。用于形式方法、系统可靠性验证之类的。我目前接触的方向，没有对这个课程的内容的使用情况，欢迎大佬补充。

GYH: 这门课程前期的学习曲线非常陡峭，你会发现在课上尝试跟上Henry节奏几乎不可能，我的最好记录是听懂前45min。需要自己在课下像持石一样把这些方法从头到尾理解每一步在干什么，然后像我上面的笔记一样整理出自己对每个题型的过程再背诵。相信有不少人都是在上完前几节课或者快期末来这里寻找可能有帮助的信息，此时心里都充满对这门课的迷茫与恐惧。但这门课在大三下是相对非常值得花时间的一门课程，如果你在为留学或保研做最后的冲击，这门课拿到A level是很重要且可以实现的，WORK HARD & GOOD LUCK.

> 春宵苦短，少女前进吧！
