## 课程介绍

线性代数是数学和工程学科的重要基础课程，研究向量空间、线性变换、矩阵理论等内容。为计算机图形学、机器学习、数据科学等专业课程提供必要的数学基础。

Xin Liu讲的深入浅出，值得跟随Profesor的思路学习
