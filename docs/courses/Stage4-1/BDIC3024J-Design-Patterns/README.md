# Design Patterns (设计模式)

> 课程编号：BDIC3024J

## 课程介绍（2025）
Haiyang Yu 五星好评，考试让人联想到高中合格考。大作业是给定一些设计模式，小组制作PPT讲解并提交一份报告。非常怀旧温馨的一门课程，有机会深度了解一些设计模式（如单例模式），可以以此为契机准备相关面试八股。

考核形式：20% Attendence + 30% Presentation & Report (Group) + 50 Final Exam

授课教师: [于海洋](https://cs.bjut.edu.cn/info/1407/1158.htm) -- 2025
