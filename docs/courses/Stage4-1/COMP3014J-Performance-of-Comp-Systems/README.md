> 课程编号：COMP3014J
>
> 考核形式：30% Group Project + 70% Final Exam
>
> 授课教师: 
> [Nima Afraz](https://people.ucd.ie/nima.afraz/professional) -- 2025


## 课程介绍
一门知识比较小众的课程，主要讲解一些仿真模拟的方法和评估一个计算机系统的策略，Nima的讲解稳定发挥，讲的不错。课程作业是一个三人合作的项目，在**VirtualBox**中的**Ubuntu**环境下使用**NS2**来评估四种TCP算法，任务是写一些python程序来测试不同环境下TCP算法的指标，最后要写一个脚本把所有python程序和其他生成文件的程序串起来一起运行。课程作业难度不大，主要是配置虚拟机时可能会出现各种各样的问题，如果个别组员出现问题建议不要花太多时间在配置上，可以去做其他文字工作。

这门课考试是***开卷***，可以自行打印全部课件（几百页）和笔记，但考试内容和开卷可携带材料并不强相关，需要较好的理解课件中内容，只追求及格建议先把计算题搞懂。
