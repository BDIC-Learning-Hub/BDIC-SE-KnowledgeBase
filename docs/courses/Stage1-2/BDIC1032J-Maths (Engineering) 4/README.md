## 课程介绍

高等数学（工）4是工科数学系列的最后一门课程，主要涵盖复变函数、傅里叶分析、偏微分方程等高级数学内容。这门课程为后续的工程分析和专业课程奠定坚实的数学基础。

### 2026 年投稿

#### 授课与考核

Lecture 由徐文青老师授课，有上海口音，听课时较难听懂，签到要求非常严格。期末考试题量和计算量较大。

徐老师在开学第一节课推荐了一本国外教材，也用这本书备课。期末考试中有很多原题和题型来自该书。
